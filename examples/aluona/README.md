# 阿洛娜练习包

下载并解压 [aluona-workshop-example.zip](aluona-workshop-example.zip)，打开包内的 `UPLOAD-WORKSHOP.md`。已经编译好，可以直接练习官方 Workshop Tools 上传。想练习从模型到工坊的完整流程，可直接把 ZIP 交给 Skill，或运行：

```bash
python3 scripts/prepare.py examples/aluona/aluona-workshop-example.zip --output ./aluona-practice
```

素材取自项目已公开发布的十五人物包，按原始资源路径仅提取阿洛娜及其依赖。原项目保留角色来源和交付记录。本示例用于本地练习，公开上传前请按原作品的许可确认分发范围。部署后在测试服输入 `!model aluona`，再用 `!model default` 恢复。
